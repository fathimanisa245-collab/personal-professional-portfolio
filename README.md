# Fathima Nisa.M.T. - Personal Portfolio

A premium, modern, responsive, and professional personal portfolio website designed to showcase my skills, projects, education, and achievements as a Second-Year Computer Science and Engineering student.

## 🚀 Features

- **Modern UI/UX**: Professional, clean, and elegant design similar to portfolios of software engineers at top tech companies.
- **Fully Responsive**: Flawless experience across desktop, laptop, tablet, and mobile devices.
- **Dark Mode**: Integrated dark theme with smooth transitions and `localStorage` persistence.
- **Interactive Animations**: Dynamic typing effects, scroll reveal animations, and animated skill progress bars using Intersection Observer.
- **Glassmorphism Aesthetic**: Modern UI elements with soft shadows and frosted glass effects.
- **SEO Optimized**: Fully equipped with meta descriptions, Open Graph tags, Twitter Card tags, and JSON-LD structured data for better search engine visibility.
- **Performance Focused**: 100% Vanilla HTML, CSS, and JS (No heavy frameworks like React or Bootstrap). Optimized for fast loading and high Lighthouse scores (Performance, Accessibility, Best Practices, SEO).

## 🛠️ Built With

- **HTML5** (Semantic Structure, Accessibility)
- **CSS3** (Flexbox, CSS Grid, CSS Variables, Animations)
- **Vanilla JavaScript** (DOM Manipulation, Event Listeners, Observers)
- **FontAwesome** (Icons)
- **Google Fonts** (Inter font family)

## 💻 Getting Started

To view the website locally:

1. Clone this repository or download the ZIP file.
2. Ensure you have the complete project structure as listed above.
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

*No installation, Node.js, or build tools required.*

## 🌐 Deployment

This portfolio is optimized for easy deployment via **GitHub Pages**. 
1. Push the code to a GitHub repository.
2. Go to Repository Settings > Pages.
3. Select the `main` branch and `/root` folder.
4. Save, and your portfolio will be live in a few minutes!
